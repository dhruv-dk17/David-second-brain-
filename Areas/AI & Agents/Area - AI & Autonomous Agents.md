# Area — AI & Autonomous Agents

> [!info] Domain Scope
> The theory, design, and practical implementation of autonomous AI agents, persistent memory systems, benchmark evaluations, and local LLM pipelines.

## Core Principles
1. **Grounding Over Hallucination**: Agents must be anchored in structured, machine-readable knowledge vaults ([[David - AI Second Brain]]).
2. **Deterministic Evaluation**: Every autonomous loop must have clear objective metrics and self-repair harnesses (as implemented in [[AI Agent - Deniel]]).
3. **Multi-Agent Orchestration**: Specialized subagents working in parallel outperform monolithic prompt chains.

## Active Projects in this Domain
- [[AI Agent - Deniel]] — Autonomous AI agent engine with self-repair and benchmark evaluation.
- [[Telecode]] — Microservices and agent skill pipelines.
- [[David - AI Second Brain]] — Obsidian-based persistent memory graph for Claude, Antigravity, and local agents.

## Key Techniques & Frameworks
- Tiered Conversation Memory (Buffer, Short-term, Long-term, Entity).
- Single-source-of-truth index routing ([[INDEX]]).
- Tool calling protocols and sandboxed terminal execution.
