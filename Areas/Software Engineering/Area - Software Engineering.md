# Area — Software Engineering

> [!info] Domain Scope
> Fullstack engineering, monorepo architectures, API design, type systems, motion design, and deployment pipelines.

## Core Principles
- **Type Safety**: Enforce strict TypeScript across frontends and backends.
- **Component Ergonomics**: Build reusable design systems with tokens before assembling complex interfaces.
- **Tactile UI/UX**: Interfaces should feel alive with micro-animations (GSAP/Framer Motion), not static text.
- **Containerization**: Standardize runtimes using Docker Compose.
