# Augmented Reality on the Web (WebAR)

> [!info] Technical Domain
> Delivering 3D augmented reality experiences directly through the mobile web browser without requiring users to download native mobile apps.

## Key Technologies
- **WebXR Device API**: Standard browser API for accessing device motion, camera passthrough, and spatial tracking.
- **Three.js / A-Frame**: 3D scene graph, shaders, lighting, and GLTF asset pipelines.
- **Applied In**: [[MyNaruto AR Interactive Experience]].
