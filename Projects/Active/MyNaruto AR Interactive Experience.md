# MyNaruto AR — Interactive WebAR Experience

> [!info] Project Objective
> An interactive web-based Augmented Reality (WebAR) application that renders 3D animated Naruto anime characters and jutsu effects into real-world camera space via browser AR.

## Architecture & Sub-Modules
- **Path**: `D:\2 web dev`
  - `MyNarutoAR/` — WebAR scene using Three.js / AR.js / WebXR marker tracking.
  - `Mynaruto2/` — Enhanced interactive character showcase with sound effects and animations.
  - `study-roadmap/` — 3D web graphics and WebGL learning milestones.

## Key Technical Takeaways
- Marker-based and surface-based tracking without native app installations.
- 3D model optimization (.gltf / .glb) for smooth 60fps mobile browser rendering.
