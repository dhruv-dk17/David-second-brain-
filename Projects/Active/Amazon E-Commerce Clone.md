# Amazon E-Commerce Clone

> [!info] Project Objective
> A complete front-end reproduction of the Amazon shopping platform, featuring responsive product catalogs, interactive cart management, dynamic price recalculation, and category filtering.

## Tech Stack & Architecture
- **GitHub**: [github.com/dhruv-dk17/amazon](https://github.com/dhruv-dk17/amazon)
- **Local Path**: `D:\amazon` (`app.js`, `data.js`, `index.html`, `styles.css`).
- **Features**:
  - Item catalog driven by structured JavaScript arrays in `data.js`.
  - DOM manipulation and event delegation in `app.js` for fast cart increments and subtotal calculations.
  - Classic Amazon UI header, search bar, navigation megamenu, and product grid.
