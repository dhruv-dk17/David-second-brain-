# Git Monorepo Splitter Tool

> [!info] Tool Description
> PowerShell automation script (`D:\split-repos.ps1`) engineered to split monorepo subdirectories into independent Git repositories while preserving commit history.

- Key Use Case: Used during the architectural refactoring of the Vinland ecosystem (`D:\Vinland` vs `D:\vinland-workspace`).
